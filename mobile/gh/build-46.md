## A. 键盘弹起时浮层跟着可视区收

用户截图：词卡里点「换个词重查」，键盘弹起后卡片底栏（更多释义 / 加入生词本）整片压在键盘下面。

根因：`.sheet-wrap` 是 `position: fixed; inset: 0`，量的是**布局视口**。这台机器的
WebView 弹键盘时不改布局视口（只改可视视口），所以 `inset: 0` 一直撑到键盘底下，
而 `50vh / 86vh` 也一动不动。

现在把可视视口写进 CSS 变量（`--vvh` / `--vvtop`），`.sheet-wrap`、`.sheet`、
词卡三档高度全部改问它；没有 `visualViewport` 的老引擎退回原来的 `vh`。

- [ ] 词卡里点「换个词重查」→ 键盘弹起 → **底栏按钮看得见、点得到**（不再压在键盘下）
- [ ] 笔记编辑面板的输入框：同样不被挡
- [ ] 键盘收起 → 卡片回到原尺寸
