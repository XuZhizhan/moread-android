## B. 本地词典 .mdx / .mdd「键区解析失败」（`37f1b3f4`）

用户两个文件（LDOCE5++ 的 `.mdx` 与配套 `.mdd`）都停在「键区解析失败」。
`.mdd` 的键通常根本不加密 —— 两个文件同一条错，说明问题不在解密，
在**键区从第几个字节开始**被写死成了规范值 `4 + headSize + 4`。

现在的做法是「候选 + 硬验收」：起点按 4 字节步长扫 `+4 / +0 / +8 … +40`，
全失败时在 header 之后 8KB 里宽扫；索引起点试 44 / 40 / 48 / 52。
验收条件没放宽：解压后长度必须精确等于声明值、键块索引刚好读完、块数吻合。

- [ ] 导入 `.mdx`（184MB，LDOCE5++）→ 能打开、能查词
- [ ] 导入配套 `.mdd` → 能打开
- [ ] 查一个词 → 释义来自本地词典（不是 AI），发音能播
- [ ] 若仍失败：截图里现在会写明**卡在哪一步、哪个候选、读到了什么数**
      （上一版只有一句「键区解析失败」）—— 把那段发回来即可定因
