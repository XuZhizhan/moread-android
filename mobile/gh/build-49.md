## A. 借阅成功立刻上书架（`807a8290`）

以前借完书切到书架**看不到这本**：书架只认「密文已经下载到本机」的借阅，
而借阅刚成功时本机一个字节都没有。更糟的是下载完成后也看不到 ——
书架同步先写数据、再算「屏幕指纹」，两次一样就判「没变化」跳过重绘，
只有重开 App 才看得到。两条都修了，规则是 11-23 你拍板的四条。

- [ ] 借一本新书 → 立刻切到书架 → 「借阅书籍」里**已经有这本**（封面可能晚一拍出来）
- [ ] 卡片上写「待下载」→ 点一下 → 封面变灰、进度条从 0 涨起来
- [ ] 下载完成自动进入阅读（也可以回书架点开）
- [ ] 长按这本未下载的书 → 菜单里有「下载到本机」
- [ ] 归还一本 → 书架里那条消失
- [ ] 断网后切书架 → 已下载的书不会被误删

## B. 书摘卡：意思 / 解析与问 AI 同一套块式（`3f9dbe7f`）

短按一条书摘 → 卡片里「意思」「解析」原来是把标签和正文挤在一行；
现在改成和当时问 AI 那张卡一样：小标题独占一行、正文另起一段、块间一条细线。

- [ ] 短按一条书摘 → 「意思」「解析」各占一块，标题在上、正文在下
- [ ] 原句被截断时两端有「…」（划了整段、卡里只显示第一句的情况）

## C. 一段里点生词优先给生词卡（`e8ed8de3`）

同一句里既有书摘又有生词时，以前点词只弹书摘。

- [ ] 点**词**的位置 → 生词卡
- [ ] 点那本书摘的**其它位置** → 书摘卡

## 已知边界

- 「下载中」的百分比只在你**从书架点下载**时显示在封面上。从图书馆页
  「我的借阅」里下载，书架要等下载完成那一下才变（不做跨页实时进度）。
- 书架上的借阅清单以**云端活跃借阅**为准：在另一台设备归还/到期，本机切一次书架就会消失。
- 离线时拉不到借阅列表，书架保留上次那一份，只清「确实已过期」的。
