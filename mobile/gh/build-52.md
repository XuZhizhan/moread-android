## 这一版解决的问题

线上 6 本书没有封面（Despereaux / Winn-Dixie / Tiger Rising / Edward Tulane /
Magician's Elephant / Mercy Watson），以前只能在书库里逐本点「选图补封面」。

先说清为什么不能自动：书进库时是**密文分片**，内容密钥按设备公钥封装，只存在读者设备上。
服务端、脚本、管理端都解不开 —— 所以「从云端把封面抽出来」这条路走不通，
能抽封面的时机只有上传那一刻，和**手上还留着原文件的时候**。

## 怎么用（管理端 → 书库 → 「从 EPUB 批量补封面」）

- [ ] 点「选 EPUB 文件…」→ 一次多选（6 本一起选）
- [ ] 逐行核对：缩略图对不对、书名对不对、**目标书**是不是那一本
- [ ] 点「开始补齐」→ 每行变成「已补上（从书里取到）」
- [ ] 游客端刷新一次，书城与详情页就有封面了

几条保命的细节：

- 匹配只认「书名规范化后完全相等」（忽略空白 / 标点 / 大小写）；同名两本时会自动选
  **唯一那本缺封面的**；两本都缺或都不缺时**留空**，必须你手动选 —— 把 A 的封面写到 B 上，
  比空白更难发现。
- 已有封面的书要**再点一次**才覆盖，防手滑。
- 只读封面，不重建书目、不动正文、不产生新版本。
