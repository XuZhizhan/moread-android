## A. 详情页：四个板块（读者端）

版式来自 handoff（390×844 设计板，四块手机是同一页的四个滚动位置，不是四个页面）：

1. **书籍信息** —— 封面（蓝思角标压在左上角外沿）/ 书名 / 中文名 + 奖章 / 作者 /
   「已读完 N 人」+「可借数/库存量」/ 出版信息两列（Publisher · Language · Page Count ·
   Copyright · Age Range · Audience · Genre · Series · ISBN）/ 数据格三格（蓝思值 · 词数 +
   章节 · 评分 + 星级）
2. **书籍详情** —— 书籍简介（分段）/ 内容摘要 / 推荐理由 / 目录（折叠，默认收起）
3. **获奖与影视改编** —— 获奖不分级平铺；没有就写「暂无」
4. **书评** —— 编辑精选；没录入就整块不显示

底栏：分享 / 预约（无库存时才出现）/ 借阅。

- [ ] 打开任意一本书：封面、书名、出版信息两列、数据格三格都在，没有横向滚动
- [ ] 蓝思值形如 `690L`（不是 `690LL`），角标与数据格显示同一个数
- [ ] 没有获奖/影视改编的书，两处都写「暂无」，不是空白
- [ ] 简介一段的书（老书）用原来那段简介兜底，不是空白页
- [ ] 底栏「借阅」文字居中、无箭头；滚到底最后一块内容不被操作条压住
- [ ] 窄屏（320）出版信息退成单列

**三处与设计稿不同**（都不是偷懒，理由见 `docs/04-design/book-detail-v2.md`）：
书单换成预约（本项目没有书单存储，放个只会变色的心形等于假按钮）、
目录折进折叠块（要能翻章，但不该多出第五个板块）、书评不放「写书评」入口（没有写书评流程）。

## B. 后台：整页「图书维护」

以前：编辑弹窗只能改 7 个字段，补封面 / 定价 / 上下架 / 删除散在列表行的六颗按钮里。

现在：列表一行只剩**「维护」**，点开是整页：

```
封面（预览 / 选图补封面 / 自动生成）
基本信息（书名 / 中文名 / 作者 / 副标题 / 分类 / 副本数 / 简介）
出版信息（出版社 / ISBN / 语言 / 页数 / 版权年 / 适读年龄 / 读者对象 / 体裁 / 系列）
阅读难度与评分（蓝思值 / 难度说明 / 词数 / 评分 + 评分数）
详情内容（简介分段 / 摘要分段 / 推荐理由增删行 / 获奖 / 影视改编 / 书评增删行）
上架与删除（上架下架 / 定价 / 删除）            [返回] [保存]
```

- [ ] 书库 → 任意书 →「维护」：整页打开，顶部是书名与状态
- [ ] 填「中文名」「词数」「页数」「版权年」「体裁」→ 保存 → 回读者端刷新，书名下方与
      数据格/出版信息里出现对应值
- [ ] 「书籍简介」一行一段、「推荐理由」点「+ 加一条理由」填标题+正文 → 详情页对应板块出现
- [ ] 「获奖荣誉」一行一条 → 书名旁出现奖章，获奖板块平铺；清空 → 显示「暂无」
- [ ] 保存成功才关页面；任一块写失败会留在页面并写明是哪一块（不会「看起来存上了」）
