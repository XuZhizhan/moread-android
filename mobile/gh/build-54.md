## 这一包与 build-53 的差别（按发布顺序）

### 1. 书架：宽屏下每本书与首页一样大（网页 18f47549）

首页内容区被限制在 520px（一行三本，单本约 154.7px），书架原来在宽屏固定 5 列铺满，
1440 宽下单本 257.6px —— 比首页大 67%，屏幕越宽差得越多。

现在从 720px 宽起，书架改成「每本至少 142px、一行能放几本放几本」：

| 屏幕宽 | 一行几本 | 单本宽 | 首页单本 |
|---|---|---|---|
| 720 | 4 | 154.5 | 154.7 |
| 1024 | 6 | 145.3 | 154.7 |
| 1440 | 8 | 157.3 | 154.7 |
| 1920 | 11 | 155.3 | 154.7 |

手机（<720px）仍是「一行三本」，没有改动。

- [ ] 电脑上打开书架：封面大小与首页一致，1440 宽一行 8 本
- [ ] 只剩两本书的分组不会被拉成半屏宽（用的是 auto-fill，不是 auto-fit）
- [ ] 手机上书架仍是一行三本

### 2. 详情页：正文排版对齐样板（网页 029e6fa3）

问题在字号偏小 13%，不是行高倍数不够。

- [ ] 简介 / 摘要：正文明显比上一包大，段落首行缩进两字
- [ ] 推荐理由：小标题下顶格，正文与简介同一字号档

### 3. 奖章：任何获奖书都有且只有一枚（网页 029e6fa3）

原来奖章写在中文书名那一行里，而那行按「有没有中文名」显隐 ——
`title_cn` 为空的书，整行隐藏，奖章跟着消失。

现在：有中文名 → 挂在中文名后（18px）；没有中文名 → 挂在主标题后（20px）。
图标是实心蓝（`#0F49CE`）。

- [ ] 打开《A wrinkle in time / 时间褶皱》：中文名后面有蓝色奖章
- [ ] 后台把某本书「获奖荣誉」清空 → 奖章消失；填回 → 再出现（不重复）

### 4. 影视改编支持多条（网页 029e6fa3）

原来是单行 input（上限 200 字），现在详情页是列表、后台是 4 行文本域，
一行一条；一条没写仍显示一条，留空显示「暂无」。

- [ ] 后台某本书「影视改编」写两行 → 详情页分两行显示
- [ ] 留空 → 显示「暂无」

### 6. 字数 / 章节数 / 页数：上传时自动检测（随 7394ec84 一起上线，内部构建号 1a21f279）

解析 EPUB 时顺手统计：汉字按字、西文按词累加；页数按 300 词/页折算（下限 1）；
章节数取目录条数（目录为空退回正文文件数）。上传建档后自动写入。

后台可以改，但不能清空：三个框留空或填 0，保存会被拦下（服务端也挡一道）。

- [ ] 新传一本书 → 图书维护里三个数已经填好
- [ ] 清空「词数」点保存 → 被拦下并提示
- [ ] 详情页数据格：词数下方显示章节数

**老书的数据现状**（生产库 39 本）：

| 字段 | 有值 | 说明 |
|---|---|---|
| 章节数 | 39 / 39 | 已从历史版本的目录记录回填 |
| 页数 | 1 / 39 | 必须重新解析正文才能得到 |
| 词数 | 0 / 39 | 同上 |

所以老书第一次点「保存」前要先把词数、页数补上，否则会被校验拦住。
不想手工填的话，重新上传一遍那本书，两个数会自动算好。
